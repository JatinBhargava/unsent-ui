## 🚀 Getting Started with Unsent (Frontend)

Unsent is a quiet writing platform — a place to write, read, and become part of others’ diaries without noise, profiles, or pressure.

This guide will help you run the **frontend** locally.

---

### 📦 Setup Steps

1. **Clone the repository**
   ~~~
   git clone https://github.com/JatinBhargava/unsent-ui
   ~~~

2. ~~~
   cd unsent-ui
   ~~~

3. ~~~
   npm install
   ~~~

4. ~~~
    npm run dev
   ~~~
