## 🤝 Contributing

We welcome all kinds of contributions — **features, fixes, documentation, and ideas**.

### How to Contribute

- Create a feature branch  
  `feature/<ticket-or-description>`

- Keep commits **small, focused, and readable**

- Open a **Pull Request** targeting the `develop` branch

### Notes

- Follow existing project structure and conventions
- Write clear commit messages
- Be kind and constructive in reviews

Every contribution helps Unsent grow — quietly and meaningfully 🌱
